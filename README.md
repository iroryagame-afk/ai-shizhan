## 公开课程页

这是 AI 新手实战课的静态页面，用来做课内演练。

- 练习是合成材料，不是真实事件、真实产品或真实测量。
- 写下的内容只在点击「保存到这台浏览器」之后，留在这台浏览器的本地存储里。
- 页面没有模型接口，也没有后台。
- 路径向公开方法帖仍是待核准候选，单独放在 `public-source-list-paths-20261123.md`，与已核内容隔离，不能当作已核事实或正确答案。
- 通过 HTTP 打开后如果断网再刷新，不保证页面还能打开。
- 无障碍没有在真机上做完全部核验。

运行页做过制作方的浏览器实际操作。码神做过独立证据审阅，马斯克做过课程边界复核。这些审阅不是独立者亲自完成界面操作，也不是全覆盖验收。

本页不是能力鉴定，也不是职业认证。「10 万」「100 万」只是可选拆解刻度，不是收入承诺。

实现规格、自测记录、截图和测试脚本不在这个公开站点里。
