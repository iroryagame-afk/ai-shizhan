# 检索索引

本索引用于按题号查找课程问题与对应模块，不作为一次做完的测验卷，也不作为能力认证。

## 使用说明

- **题号对照**：本索引使用 Q001–Q089 题号，方便按号查找；与正式测验稳定 ID 的对应关系，以每条的状态和备注为准。
- **收录口径**：本索引含 89 条检索问题，另有 N01–N11 共 11 条候选新条目；正式测验题面是否已写入，以每条的状态为准，尚未补齐的条目不计为已完成。
- **测验与毕业范围**：日常学习主要做开场诊断、模块练习和毕业题，具体测验题数以《题库》为准。任何路径都不可跳过 M3；跳过 M6 仍可毕业；主路毕业须完成下周可核对任务、M1 任务卡、M2 对照、M3 核验、M5 课内关卡与 M7 复述。M4 可学习和复用，但不另加毕业硬门槛；M6 是选修，可跳过。授权、隐私与状态证据关键题须全部答对。
- **阶段标签说明**：课内使用的阶段标签 S1–S4（入门/会用/会改/会建）是学习推荐，不是能力鉴定或职业认证；阶段高也不能跳过安全核验。
- **状态含义**：
  - `已重写题干并写入题库`：只用于索引题号与测验稳定 ID 同号（本版为 Q001–Q008）。
  - `主题已覆盖，对应测验 <真实ID>`：非同号题的主题已有明确测验覆盖，须按列出的稳定 ID 跳转；不代表该索引题的同号正式题面已写成。
  - `已重写索引题干、正式测验题面待补`：已完成检索题干改写，正式测验题面后续补齐。
  - `已合并到某题`：与指定题号主题高度重叠，统一归并到目标题号口径，避免重复定义。
  - `候选待审，尚未写入正式测验`：暂用 N 编号登记的候选新条目，尚未写入正式测验。
